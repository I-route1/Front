# 저장된 AI 리포트 화면

학부모의 AI 리포트 화면과 학원의 학생 상세 > 리포트가 `GET /api/counseling/reports?studentId=...`를 공통 인증 클라이언트로 조회한다. 계정 ID 대신 실제 학생 ID를 전달한다.

- 기존 과목별 카드의 색상·순서·본문 표시를 유지한다. 각 카드에서 저장 이력을 최신순으로 선택할 수 있다.
- `subject`를 기준으로 수학·국어·영어·과학·사회·통합을 구분한다. 과목 정보가 없는 기존 기록과 지원 목록 밖의 과목은 별도의 미분류 카드에 표시한다. 제목으로 과목을 추측하지 않는다.
- 새로고침·다른 계정·브라우저에서도 서버 이력을 조회한다. 기존 sessionStorage의 리포트 결과는 조회 권한의 근거로 사용하지 않는다.
- 생성 성공 후 저장 이력을 다시 조회한다. 과목별 최신 이력과 이전 이력을 모두 선택할 수 있다. 결과 닫기는 접기 동작이며 서버 기록을 삭제하지 않는다.
- 로딩·빈 이력·403 등 조회 오류를 구별하고 재조회할 수 있다. 만료 토큰은 기존 공통 클라이언트가 갱신한다. 학생/계정 변경 뒤 늦은 조회·생성 응답은 새 학생 화면에 반영하지 않는다.
- 저장 이력 조회는 AI 서버를 호출하지 않는다. 새 생성은 기존 AI 서버 연결이 필요하며 프리미엄 생성은 기존 크레딧 정책을 따른다.

검증은 `npm run test:learning-records`, `npm run test:learning-records:browser`, `npm run build`로 실행한다. 브라우저 테스트의 서버 응답은 테스트 전용 데이터이며 운영 리포트를 생성하지 않는다.
